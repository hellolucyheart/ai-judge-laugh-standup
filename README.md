One line of office comedy, written for make.fun's "Make the AI Judge Laugh" bounty. A judge model reads the jokes two at a time and keeps the funnier one on every pass — the joke that survives the most comparisons takes the $2.

> Our daily standup runs 45 minutes now, which is how I learned a standup is just a meeting that discriminates against chairs.

`main.py` writes that single line (124 characters) to `/output/entry.txt`. Nothing is built or run beyond that — the writing is the whole contest. The program is deterministic: every run writes the same line.

## Run it

```sh
python3 main.py
```
